Design Your Game

Step 1: The Concept

Decide three things:

  • Setting — where is your game?
  • Goal — what does the player need to do to win?
  • Obstacle — what's in the way?

You don't need to tell the player how to win. That's part of the fun.

Step 2: Draw Your Map

On paper:

  • Draw a grid — one square per room
  • Number each room (start at 1)
  • Label with a short name
  • Draw arrows for exits (use compass directions + UP/DOWN)
  • Mark one-way routes with a single arrow

Tips:

  • 6–10 rooms is plenty to start
  • Plan a route from start to finish
  • Add dead ends to make it interesting
  • Mark where items and puzzles will go

Draw your map now! (10 mins)

Step 3: Plan Your Items & Puzzles

On your map, mark:

Items

  • Things the player can pick up
  • Things that are too heavy to move
  • Things needed to solve puzzles

Puzzles

  • USE item in room → unlock exit
  • Reach room with item → win!
  • Enter room → danger!

Add Puzzles

Edit puzzles.csv

How puzzles work

Each row is one effect. A puzzle can have multiple rows.

trigger → conditions → effect

Triggers

USE item MOVE to room GET item DROP item


Conditions

condition_item — must be carrying
condition_not_item — must not carry
condition_room_item — item in room

Effects

ADD_EXIT REMOVE_EXIT SET_ROOM_DESC SET_ITEM_SHORT_DESC SET_ITEM_LONG_DESC PRINT_MSG WIN LOSE


Options

message — text to print
delay — pause in seconds
once — True / False

Puzzle: unlock a door

USE KEY in room 3 → print message, add exit NORTH to room 4

trigger_verbtrigger_itemtrigger_room effect_typeeffect_targeteffect_value messageonce
USEKEY3 PRINT_MSG—— The lock clicks open!True
USEKEY3 ADD_EXIT3NORTH:4 —True

once: True — fires once only. The door stays open. The wall stays broken.

Puzzle: win condition

MOVE to room 8 while carrying the gem → WIN

trigger_verbtrigger_room condition_itemeffect_type messageonce
MOVE8 GEMWIN You escaped! You win! 🎉False

condition_item — player must be carrying this for the effect to fire.

condition_not_item — fires only if player is not carrying this.

Puzzle: instant death

MOVE to room 5 → dramatic pause → LOSE

trigger_verbtrigger_room effect_typemessage delayonce
MOVE5 PRINT_MSGThe floor gives way beneath you... 2False
MOVE5 LOSE— 0False

delay — pause in seconds before the next effect. Great for drama.

Add at least one puzzle: a win condition, a locked exit, or a death trap. (15 mins)

USE KNIFE in a room containing SACKS → change the item's description

Test Your Game

Play through it yourself:

  • Can you win?
  • Are all rooms reachable?
  • Do your puzzles trigger?
  • Does CHEAT 5 help you jump around?

Common issues:

  • Exit goes to wrong room number
  • Item name in puzzle doesn't match CSV exactly
  • trigger_room is wrong
  • once=True but you need it to repeat
Give 10–15 minutes of free testing time. Circulate and help debug.

Save Your Work

with Git

Commit your changes

A commit is a snapshot of your work with a message explaining what you did.

$ git add rooms.csv items.csv puzzles.csv
$ git commit -m "Add my haunted school adventure"
[workshop abc1234] Add my haunted school adventure
3 files changed, 47 insertions(+)

Commit often — after rooms, after items, after puzzles. Each commit is a save point you can go back to.

Push to GitHub (stretch)

If you have a GitHub account, you can put your game online:

$ git push

Then share the link and someone else can clone your repo and play your game.
